- Kit PDF: the trust legend ("How to read these numbers") no longer splits across a page break (#749, epic #244). Chromium paints the audience summary plate after the page's running text, so a legend cut by a page break had the plate's text between its halves in the PDF text, and the text check could not find the legend sentences as written. The print stylesheet now keeps the legend whole. This showed up only with a real Chromium (`pytest --run-visual`); the check itself is unchanged.
