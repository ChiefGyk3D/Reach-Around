- Fediverse collector slice 1, the shared plumbing (#921, design in `docs/design/fediverse-collector.md`, epic #244). New `fetch_json_array` beside `fetch_json` returns a top-level JSON array with a read-only view of a few response headers (`Link`, `Retry-After`, `Date`, rate-limit headers), under a hard 1 MiB cap, with the same https, host, redirect and fixed-error-word rules; `fetch_json` is unchanged. New pure 30 day window helper (server-assigned `created_at` or `indexedAt` only, clock passed in), the aggregate-only `{boosts, favorites, replies}` row with a `NotProvided` marker so an incomplete read keeps the prior values and is never a zero, and a hand-run probe `scripts/fediverse-probe.py` that prints status codes, header names and counts only and is not run by CI. No provider and no live host yet; the Bluesky and Mastodon providers are #922 and #923.
