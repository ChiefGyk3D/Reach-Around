- Tighten credential handling in the count collectors (#765): the YouTube and Twitch app-credential calls now run in narrow helpers that clear their credential locals and return fixed words; a Meta token sink must return exactly `True` to count as stored; the Twitch refresh token from the environment is length and character checked like the other credentials; a Twitch refresh reply is checked for token type, lifetime and scope before the new pair is used (a reply that fails the check is dropped, not stored); the Doppler token read from stdin is bounded; and the Doppler secret sink caps the encoded request size and sizes its response cap so a successful store of non-ASCII values is no longer reported as failed.
