- Editor (#204): the preview now shows the real built site instead of a placeholder. The site is rebuilt after each change that is saved, undone or redone (and after an edit made outside the editor), and `state.build` reports a real build error, not only a config that fails to load. A failed build keeps the last good page on screen. The preview listener serves only the build output, with a policy that allows images from the page itself and `data:` only; the new `reach-around edit --allow-remote-images` flag also allows `https:` images. Build files are opened once, one path segment at a time from the build root's descriptor without following links (a link or a swapped directory on the way is refused), checked on the open descriptor, dropped mid-send if the file shrinks, capped at 64 MiB and sent in 64 KiB chunks (at most 8 at a time); and the first state load after start always rebuilds the current config. The build folder must be private to the current user (owned by it, mode 0700, as the editor creates it) or the editor refuses to serve; that invariant is why same-device bind mounts are not detected. The count of files dropped mid-send is updated under a lock.
