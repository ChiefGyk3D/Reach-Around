- Editor (#204): the preview now shows the real built site instead of a placeholder. The site is rebuilt after each change that is saved, undone or redone (and after an edit made outside the editor), and `state.build` reports a real build error, not only a config that fails to load. A failed build keeps the last good page on screen. The preview listener serves only the build output, with a policy that allows images from the page itself and `data:` only; the new `reach-around edit --allow-remote-images` flag also allows `https:` images.
