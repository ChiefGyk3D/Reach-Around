- Edge settings checker (#613): `scripts/check-edge.py --offline` now reads `deploy/edge/*.tf` with a small tokenizer instead of counting braces per line. Quoted strings are single tokens, so a brace inside one (or an escaped quote before it) can no longer move a block boundary; a brace in a string, interpolation, a second block on one line, a lone carriage return and anything the tokenizer cannot parse all fail closed. The `terraform` and `variable` blocks are checked against an attribute allowlist. Tests in `tests/test_edge_settings.py` cover each case.
