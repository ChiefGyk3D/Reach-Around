- Docs accessibility check (#816, epic #795): new `scripts/check-wiki-a11y.py`, stdlib only, scans `docs/wiki/` (or the paths given) and prints `path:line: rule` for pages without exactly one H1, skipped heading levels, empty headings, vague or bare-URL link text, raw URLs in prose, tables with an empty header cell, code fences without a language, images with empty or filename-like alt text, and image assets that are unsafe on a dark background (opaque PNG, white SVG fill; an allowlist file covers intentional photos). Run it with `python3 -I scripts/check-wiki-a11y.py`; a pytest test runs it over the wiki. The wiki pages it found were fixed: code fences now name a language and two tables have a labeled first header cell.
