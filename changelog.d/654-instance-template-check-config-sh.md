- Instance template `check-config.sh` pulls the pinned engine image first (#654, epic #246): on a fresh runner the container runtime's pull progress on stderr was read as "the engine could not run the check", so a valid config exited 3. The script now checks for the pinned image (`image inspect`), pulls it quietly when missing, and fails with its own message and status 3 if the pull fails. The check run itself is unchanged: any stderr from it, a crash, or a status other than 0 or 2 still exits 3, and the pinned digest is checked as before. Works with Docker or Podman. Tests cover both runtimes with a fresh-runner case, an invalid config, an engine crash, and a failed pull.
