- Tests (#937): the instance template tests that read the pinned engine workflow no longer fail now and then on one Python job. Parallel test workers fetched the pinned commit into the same shallow clone at once and one of them lost the race for git's shallow lock; the fetch is now serialized across workers, retried up to three times with a short backoff, and a failure names the git message so a failed fetch is told apart from a commit that was never asked for.
