- Group-level analytics rollup (#678, epic #667): new `reach-around report --config site.yaml` adds "Link clicks by group" to the text, JSON and CSV (`groups.csv`) reports, one row per group (tab) and route class (`link` or `social_icon`). A row is only the sum of link rows the report already prints, so it reads as at least that many clicks, and it adds no figure beyond the link tables. There is no "Under 5" or `withheld` row per group: a status taken from a hidden group total is an oracle (two configs that group the same hidden ids differently pin each one to exactly 1), so a group with no printed row is left out and the section is empty when a link table is withheld. With `--config` the report also prints a separately versioned rollup digest (v1) of the printed rollup only: the printed id to group assignments, the rows and state, floor, `--top`, period, offset and kind. It leaves out the private core digest (a hash of the input cells, which could be brute-forced against it) and so does not bind the ledger entry; the ledger digest is unchanged. Two exports with identical printed assignments, rows, state and bound parameters give the same digest. No new collection, service or personal data; the beacon and the Worker are unchanged. Group names in `groups.csv` go through the report's existing spreadsheet-safe cell encoder (a leading `=`, `+`, `-`, `@`, tab or CR gets a single quote). Without `--config` the report is byte for byte as before. Not part of this change: the owner HTML page and the Grafana export. Docs: `docs/report.md`.
