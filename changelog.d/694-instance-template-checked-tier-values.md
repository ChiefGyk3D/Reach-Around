- Instance template tier settings (#694): `scripts/check-tiers.sh` compares staging and production settings after normalization (lowercase; one trailing dot and a default port removed from hosts and zones; non-ASCII names must be written in `xn--` form; rate-limit namespace ids are ASCII digits compared as integers). Required settings must be present: staging always, production as a set once any production setting or `ALLOW_PRODUCTION_DEPLOY` is set. `validate` writes the checked values as job outputs and the four deploy jobs read only those outputs, so the checked values are the values deployed. New tests cover each rule, and the release-tag tests assert the exact grammar error and fail when the grammar is loosened.
