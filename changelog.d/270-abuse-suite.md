- Media kit gate tests (#270): added an abuse suite for the Worker gate, view page, unlock cookie and inquiry form (`worker/test/abuse/`), covering forged and expired cookies, revoked sessions, malformed and oversized bodies, injection in addresses and alert text, budget and allowance exhaustion, concurrency, and leakage in stored data, logs and error responses. Added a deterministic mutation check (`scripts/mutation-check.py`, list in `scripts/mutation-check.toml`) that applies named edits to a temporary copy of the gate source and requires a test to fail for each; the repository tree is never modified. How to run it and what it does and does not prove: `docs/security/abuse-suite.md`.
