- Instance template deploy (#694): the deploy documentation and workflow comments now say exactly when each tier runs. Staging runs on a push to `main`, or by hand on `main` with target `staging`, only while `ALLOW_STAGING_DEPLOY` is exactly `true`; otherwise only `validate` runs. Production runs only by hand on `main` with target `production` while `ALLOW_PRODUCTION_DEPLOY` is exactly `true`. New tests read the parsed workflow and bind every deploy input of every deploy job to exactly one validate output or literal per tier (staging jobs read only staging outputs, production jobs only production outputs), fail when a production job reads a staging output, and fail when an input is added until it is mapped.
