- Kit v2 slice 7, the owner-only measures file (#632, epic #244): new `reach-around kit measures --config --site-out --gated-out --out-dir` writes `kit-measures.json`, the public and gated measures the kit shows, each with its trust label, date and period, for the sponsor page and quote to read (and nothing else for a measure value). It is never published: it goes to an owner-only directory outside the site output, the gated directory, the config directory and any git work tree (the same rules as the private PDF), is mode 0600, and its name is in no published artifact (a test walks both output trees). A measure of a private field is never in it, and the text is searched for every private figure and not-for-PDF value before anything is written; a hit names the field, never the value. The gated page's policy record must match the display policy, and a kit with no measures writes no file. The schema is versioned (`schema_version` 1) and documented in `docs/kit.md`; `load_measures_file` is the one strict reader (refuses links, large files, duplicate or unknown keys, other versions and private rows). The kit still computes no price. Tests: `tests/test_kit_measures_file.py`.
