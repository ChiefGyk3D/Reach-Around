- Kit v2 slice 7, the owner-only measures file (#632, epic #244): new `reach-around kit private-measures --config --site-out --gated-out --out-dir` writes `kit-measures.json`, the public and gated measures the kit shows, each with its trust label, date and period, for the sponsor page and quote to read (and nothing else for a measure value). It is never published: it goes to an owner-only directory outside the site output, the gated directory, the config directory and any git work tree, is mode 0600, and its name is in no published artifact (a test walks both output trees). The build now also writes `kit-binding.json` in the gated directory (digests of the policy, the resolved measures and both kit pages), and `kit private-measures` refuses unless the config, numbers and both directories match that one build. Private values (whole numbers, decimals, negatives, imported values and free text) are checked as decoded values against an inventory of the private sources before anything is written, numbers by magnitude in any common written form (separators, fullwidth digits, invisible characters), numbers of 6 or more digits also with every separator removed (a deliberate fail-closed rule: an unrelated pair such as "123, 456" can stop a build, and the error says to reword), short figures when written with a unit or as a measure row with a unit, and a hit names the field, never the value. The output directory is opened component by component from the root and kept open through the write, and is checked again just before and after the rename (the private PDF uses the same code); it warns when the parent folder can be written by the group or others, and the docs say what a path check cannot see and that private output belongs in a folder only the owner can write; a directory that holds a git work tree below it is refused. A kit with no measures writes no file. The schema is versioned (`schema_version` 1) and documented in `docs/kit.md`; `load_measures_file` is the one strict reader and checks the type and format of every field. The kit still computes no price. Review round 1 fixes: `load_measures_file` now recomputes the digest of the rows it loads and refuses a row edited after the build even with a genuine binding; a private decimal is also found written with a decimal comma, spaced punctuation, other scripts' digits or scientific notation; a kit with public measures only now gets a binding with a null gated page and can produce the file (the gated directory must then hold no page); and every directory above the output folder's parent must belong to you or root and not be group or other writable unless sticky, or the write is refused. Tests: `tests/test_kit_measures_file.py`, `tests/test_kit_pdf_output.py`. Review round 2 fixes: a private figure shown as the value of a measure row (a percent row stores tenths, so 123 is 12.3%) is now found, decimals and long numbers included; more written forms of a decimal are found (superscript exponents, a spaced mantissa, other multiplication signs, the Arabic decimal and thousands separators, regional grouping, a middle dot or apostrophe as the point), and the docs now name what is not read (words, fractions, Roman numerals, other bases); the row-validation tests re-digest the rows so each fails when its own check is removed (#632).
