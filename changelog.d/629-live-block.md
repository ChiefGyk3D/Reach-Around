The block follows config order and is never sorted by size; each typed figure prints its UTC period and the Hand-kept label, a figure left out prints "Not entered" and a platform with none prints "No live numbers yet". Nothing beyond the public follower count is read from an API: the rows have no source setting. Each live measure is never visible more widely than the field it came from. Both PDFs print the block and their text check expects it.
