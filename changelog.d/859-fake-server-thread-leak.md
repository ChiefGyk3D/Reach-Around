- Tests: fake servers no longer leave threads behind. The raw-socket test server now wakes, closes and joins its accept and worker threads, and the loopback HTTP test server joins its handler threads on close, so a late socketserver traceback can no longer land in another test's captured stderr (#859, epic #757). A handler error in the loopback server now fails the test at close() instead of vanishing, close() has one deadline that includes shutdown, and finished workers are dropped. A new test counts threads before and after to catch a server left running.
