- Tests: fake servers no longer leave threads behind. The raw-socket test server now wakes, closes and joins its accept and worker threads, and the loopback HTTP test server stops its accept loop, then joins every handler thread, on close(), so a late socketserver traceback can no longer land in another test's captured stderr (#859, epic #757). Each handled connection keeps its own error record: a failure in a handler, or in starting one, fails close() with its traceback, and only a client hang-up raised while reading the request is ignored. close() has one deadline that includes shutdown, is safe to call twice, and never starts a second shutdown helper. New tests count threads by identity before and after to catch a server left running.
