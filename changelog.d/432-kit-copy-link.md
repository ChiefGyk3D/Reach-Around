- Kit copy-link control (#432, epic #244): the public kit page shows its own address as visible link text with a "Copy link" button that appears only when script runs. The button uses the browser clipboard API only, announces the result in an `aria-live` status region, and selects the text where the clipboard is unavailable. The address comes from config (`kit.public_url`, or `page.url` plus `/kit/`), carries no query string or fragment, and is never read from the request. There is no share-to-network button, no third-party script and no request; the script is one same-origin file under the existing strict CSP. `kit.copy_link: false` turns it off; without an address nothing is printed. The gated page, the retry page and the public PDF carry no control. Tests in `tests/site/test_kit_copy_link.py`; docs in `docs/kit.md` and `docs/config.md`.
