- Support page: QR codes made at build time from the validated address (#713, epic #509). New `support.qr` (default off). On, the build writes `support/qr-N-<digest>.svg` for each coin (the digest is the first 32 hex of the SHA-256 of the file's bytes, so a cached file is never shown for different bytes; the files are cached as immutable and the page revalidates) using a small encoder in the engine (`reach_around/site/qr.py`, no new dependency, no network, no third-party service) and shows it in a closed "Show QR code" drawer. The code holds the bare address (byte mode, level Q, 4 module quiet zone), is drawn dark on a soft gray tile, and is compared with the encoder's output for that address at build time. The strict support page check now allows exactly that drawer and still refuses every other image, link or attribute; the `/support/` policy stays `img-src 'self'`. A coin's own `qr:` image path is still refused on this page. Tests in `tests/site/test_support_qr.py` decode every code with an independent reader and check the round trip.
