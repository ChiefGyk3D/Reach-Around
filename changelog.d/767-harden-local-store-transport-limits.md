- Harden the local snapshot store and transport limits (#767): the store file is opened without following links, must be a regular file owned by the running user, and is always set to mode 0600 (also when it was 0400, 0200 or 0000); every directory above it must be a real directory (no symlinks), owned by the running user or root, and not writable by group or other (a sticky directory is tolerated above the immediate parent, which must be the user's own), and each new connection re-checks that the path still names the same file, because SQLite opens by pathname and cannot take a descriptor; a re-written observation is skipped as unchanged only when every stored field matches (expiry, access, note and time zone included); store reads refuse past a fixed row cap instead of loading without bound; click totals stay exact integers under a fixed bound (new migration 0002 rebuilds the table with a type check); the Beacons CSV reader stops at the row cap while streaming; and the pinned HTTPS transport tries at most four distinct checked addresses within the one deadline. A store that has not yet applied migration 0002 applies it on the next `store migrate`.
