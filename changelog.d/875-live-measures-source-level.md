- Kit live measures took their visibility from KIT_FIELD_POLICY alone, so narrowing the live field in DISPLAY_POLICY did not narrow them; every measure builder now derives visibility through source_level, the narrower of both tables, and that is the actual fix. Regression tests run each registered builder with every measure it can emit under each narrowed table, and a static scan flags an unlisted builder where it can see one; this is best-effort protection, not a completeness proof, since a builder made through getattr or type(...) escapes the scan (#875, epic #244).
