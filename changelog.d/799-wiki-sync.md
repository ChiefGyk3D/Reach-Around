- Docs: publish docs/wiki/ to the GitHub Wiki from main (#799, epic #795). New `.github/workflows/wiki-sync.yml` calls the shared GYST `wiki-publish.yml` (pinned by commit): it runs on a push to main that touches `docs/wiki/**` or by hand, never on a pull request or in a fork, queues syncs, skips with a message while the repository wiki is switched off, and runs `scripts/check-wiki-scrub.py` first when that file exists. Only the publish job holds `contents: write`; it commits as `github-actions[bot]` with the job token. New `scripts/wiki-flatten.py` (stdlib, tested offline) flattens the folders into the wiki's flat layout (`a/b/c.md` becomes `a-b-c`, `index.md` or `README.md` names its folder, `Home.md` required, a sidebar is generated when none is authored) and rewrites relative links. Nothing is published until the owner switches the wiki on and creates its first page; no repository setting changed.
