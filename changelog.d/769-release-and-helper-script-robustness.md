- Release and helper scripts are more robust (#769). Release runs share one repository-wide queue and a tag that is no longer the highest release tag is refused, so an older tag cannot overwrite the newest image tags. The page-id check rejects an oversize page instead of reading part of it. The local gate lints changed workflow files (actionlint and zizmor, failing when neither is installed) and reinstalls worker dependencies whenever the lockfile changed. The smoke script ignores a user curl configuration file. The cache purge step retries a rate-limited batch after the server's Retry-After wait, within its time budget. The brand token drift check pins its generator by hash. The Turnstile storage check's strict mode now accepts each mode's documented success state. A release tag must be exactly vMAJOR.MINOR.PATCH (ASCII, no leading zeros, no prerelease or build metadata); any other tag is refused. The release also checks that the tag still points at the released commit, and `latest` and the major.minor image tag move only in a final job that checks the tag again. The gate passes workflow file names to the linters after a separator and rejects unexpected names. A failed cache purge logs only the HTTP status and numeric error codes, never the response body.
