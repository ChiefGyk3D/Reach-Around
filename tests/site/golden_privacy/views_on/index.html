Privacy

This page lists everything this site collects, why, and for how long. It is generated from the features the site uses.

  • When you click a link, the site stores the link, its source label, and the hour. Labels outside the creator’s fixed list count as “other.” Missing or unusable labels count as “none.” The record has no IP address or country. Separate daily totals count clicks by source and by country. Source and country are never combined or linked to a page view or person. The site honors Global Privacy Control and Do Not Track for link clicks. If your browser sends either signal, the click is not counted or stored, and the site's own script sends nothing. If scripts are blocked or fail, your browser may still send a small request to the site. The server throws it away without storing anything about it. The link still opens normally.

    Why: These records count link clicks and show daily totals by source or country.

    Kept: Hourly records are deleted after 90 days. Daily counts are deleted after 90 days. Monthly totals are kept for up to 25 months.

    This is not sensitive data.

  • This counter counts this site only. If it ever counts another site, the counts are kept separately and this page names it. Each view records the page, referring site’s name, campaign and source labels, one of four window sizes, and the hour. It keeps browser and version, operating system, device kind, language, and the location detail enabled: country, region, and city. It marks the view as likely human or automated and gives a short reason. Source labels outside the site’s list count as “other.” Labels use lower-case letters, digits, and hyphens, with a 30-character limit. The server creates a daily code from the address and site name. It cannot reveal the address. Short hashed counters limit flooding. The IP address and raw browser identification are never stored. The counter stores nothing in your browser.

    Why: The daily code counts one person once per day on one site. Short counters stop one client from flooding the counter. Global Privacy Control and Do Not Track stop all view data from being sent. Small groups are combined as “other.”

    Kept: View records are normally deleted after 7 days. If the site has not yet added a day's records to its daily totals, the records are kept longer so the totals are not lost. After 21 days, they are due for deletion no matter what. They are removed during the next cleanup runs, which can occasionally be delayed for a short time. The daily code is deleted at the end of each day. Abuse counters are deleted within about two hours. Anonymous totals are deleted after 90 days. Records do not identify anyone, so records for a specific person cannot be deleted.

    This is not sensitive data.
